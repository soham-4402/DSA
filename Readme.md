# Data Structures & Algorithms in C++

A collection of Data Structures and Algorithms implementations and practice problems written entirely in **C++**.

## Topics

- Arrays and strings
- Linked lists
- Stacks and queues
- Trees and binary search trees
- Heaps and hash tables
- Graphs
- Recursion and backtracking
- Searching and sorting
- Dynamic programming
- Greedy algorithms
- Bit manipulation

## Getting Started

### Prerequisites

- A C++ compiler with C++17 support, such as `g++` or `clang++`

### Compile and run

Compile any solution directly from the command line:

```bash
g++ -std=c++17 -Wall -Wextra -O2 path/to/file.cpp -o solution
./solution
```

## Repository Structure

Solutions are organized by topic where possible. A typical layout is:

```text
.
├── arrays/
├── linked-list/
├── trees/
├── graphs/
├── dynamic-programming/
└── sorting/
```

Each `.cpp` file is intended to be self-contained and may include example input/output in comments.

## Conventions

- Use clear, descriptive names for functions and variables.
- Mention time and space complexity with each solution when practical.
- Prefer iterative or recursive approaches based on readability and constraints.
- Keep solutions in standard C++ without external dependencies.
